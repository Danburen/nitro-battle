# AI 外交倾向（v2）——附庸国扩展

本文档在 v1 基础上增加“附属于宗主国”的 AI 倾向维度。v1 的九种倾向、五维数值、阈值换算、观察入口全部保留不变，仅做增量。

## 1. 设计原则（补充）

- 附庸类型（合作 / 自治 / 压迫）是外交关系状态，可转换、可脱离；`tendency` 是国家固有性格，世界生成时固定。两者正交，不互相覆盖。
- 新增**第 6 维 `subservience`（臣服度，1–5，3 中性）**，只对附庸国生效；非附庸国该维等价于中性 3，不参与任何阈值换算，保证 v1 九种倾向行为完全不变。
- 附庸 AI 仍只通过 `AIAction` / 领域函数的校验路径行动，臣服度只移动决策阈值与随机权重，不改变规则。控制器与外交模块继续从 `game/ai/tendencies.ts` 读取同一份 `AITuning`；附庸阈值由新增的 `vassalTuning()` 导出，与 `tendencyTuning()` 并列。

代码结构：

```
src/game/ai/
  types.ts        AIController / AIAction / AITendencyId / AITendencyProfile / AITuning / VassalTuning
  tendencies.ts   9 种倾向、六维数值、阈值换算、vassalTuning()、种子洗牌、tooltip 文案
  standard.ts     StandardAI：攻击、推进、建造、征兵
  index.ts        统一出口
```

## 2. 臣服度基线（九种倾向 × subservience）

世界生成时按 seed 在基线上 ±1 抖动，钳制在 1–5，并存到 `Nation.subservience`；阈值读取时优先使用该值，缺失时回落到倾向基线。

| 倾向 | subservience | 行为倾向 |
| --- | --- | --- |
| 和平主义 | 4 | 不愿打仗，依附强权换安全。 |
| 专注防御 | 3 | 只关心边防，对宗主中立。 |
| 恃强凌弱 | 2 | 欺软怕硬，对强者不服。 |
| 机会主义扩张 | 2 | 随时准备换边，忠顺度低。 |
| 霸权争雄 | 1 | 自身有霸权野心，最易脱离。 |
| 贸易立国 | 4 | 依附宗主保商路。 |
| 意识形态输出 | 2 | 宗主意识形态不同时更低。 |
| 孤立堡垒 | 3 | 不关心宗主，只想自守。 |
| 军国动员 | 2 | 军事自主倾向强，不愿被指挥。 |

## 3. 附庸类型与臣服度的交集

三种附庸类型参数沿用现有 `VASSAL_PROFILES`（合作 / 自治 / 压迫的资源比例、政治点上缴、独立性初值、请愿代价与幅度），不重复定义。臣服度只调节行为倾向，不修改 profile 静态参数。

- **合作型**：`canPetition = true`，但 `raiseIndependenceWill` 由臣服度决定——忠顺的合作型不会主动提独立，桀骜的会频繁请愿。请愿代价沿用 profile 的 25 政治点 / +12 独立性，冷却 15 天。
- **自治型**：请愿代价很低（12 政治点 / +12），subservience 低的国家会迅速把独立性拉满并寻求脱离；高臣服度的自治型则安于现状。
- **压迫型**：`canPetition = false`，`raiseIndependenceWill` 强制为 0，但 `independenceDrift` 仍生效——桀骜的压迫型附庸会被动涨独立性直至叛乱，这正是“无博弈榨取但易叛乱”。

## 4. 附庸专属阈值 `vassalTuning(profile, vassalType, subservience)`

| 阈值 | 公式 | 作用 |
| --- | --- | --- |
| `independenceDrift` | `(3 − subservience) × 0.5` | 每回合独立性被动变化，正数上涨、负数下降 |
| `raiseIndependenceWill` | `clamp(0.15 × (3 − subservience), 0, 1)`，压迫型恒为 0 | 附庸主动提出主权请愿的概率 |
| `tributeCompliance` | `0.7 + 0.1 × subservience`，范围 0.8–1.2 | 实际资源缴纳 = 基础比例 × 该系数 |
| `callToArmsAccept` | `0.3 + 0.15 × subservience`，上限 1 | 宗主召唤参战的接受率 |
| `overlordTrust` | `subservience / 5` | 宗主对其信任，影响契约改善决策 |
| `defectRisk` | `(6 − subservience) / 5` | 独立性达阈值时倒向他国的权重 |

## 5. 附庸 AI 动作（走与玩家相同的校验路径）

- `petitionIndependence`：`canPetition` 且 `will > rand()` 时触发，校验政治点 ≥ `petitionCost`、独立性 < 100、冷却已结束。一次请愿直接 +`petitionGain`（合作 12 / 自治 12），随后进入 15 天冷却；压迫型永远不触发。
- `requestUpgrade`：压迫型或合作型且 `subservience ≥ 4` 时触发，校验宗主关系、政治点 ≥ 10、当前契约仍可改善。改善路径：压迫型 → 合作型，合作型 → 自治型。
- `defectTo`：独立性 ≥ 阈值（合作 80 / 自治 70 / 压迫 90）且 `defectRisk > rand()` 时触发，校验存在可倒向的第三方（与旧宗主交战或接壤，且实力不低于旧宗主的 0.6 倍）。玩家不会被静默设为新宗主。
- `acceptCallToArms`：宗主召唤时 `callToArmsAccept > rand()` 时接受，校验战争状态；玩家附庸收到待处理请求，拒绝会提高独立性。
- `requestForeignAid`：压迫型附庸仍可按冷却向非宗主国求援。

## 6. 观察入口与 tooltip

按 v1 第 5 节格式，附庸国国家卡片在“外交倾向”之后追加一段附庸状态，示例：

```
[[chip:#38d64b|格拉联邦]]
这个国家不结盟、不扩张、也不干涉他国，只在边境重兵设防，坚持武装中立。

+重视边防与工事，遭到入侵时坚决反击
~不愿主动开战，更倾向维持现状
~对扩张领土兴趣不大

附属于：[[chip:#c0392b|北方帝国]]（合作型）
独立性 32 / 100 · 上缴资源 15%
+忠顺：主动配合宗主战争，缴纳稳定
```

臣服度染色：`subservience ≥ 4` 用 `[[pos:…]]` 写“忠顺”，`≤ 2` 用 `[[neg:…]]` 写“桀骜”，3 用 `[[note:…]]` 写“中立”。压迫型额外显示 `[[neg:独立性不可主动提升]]`。五维与臣服度数值、阈值权重等实现细节不在玩家文案中出现，只保留在本文档。

入口位置：

- 省份 / 州情报面板：外交倾向 `(i)` 追加附庸状态；
- 外交面板国家卡片：外交倾向 `(i)` + 独立的附庸状态行；
- 开局巡视的「国家详情」面板：同上；
- 玩家作为附庸时，外交面板顶部显示附属于哪国、独立性、贡赋、附庸态度与改善契约按钮。

## 7. 世界生成中的附庸

- 5 国以上开始生成附庸：5–7 国 1 个，8–9 国 2 个，10 国以上 3 个。
- **割地附庸**：从 AI 大国的边境州中切出一个新小国（不切断宗主首都连通性），作为该宗主的合作 / 自治 / 压迫型附庸。
- **独立附庸**：把已有的弱小国家附属于一个接壤且明显更强的邻国。
- 只生成一层关系：附庸不再拥有附庸，宗主国不会同时是别人的附庸。

`tendencyTuning()` 的 v1 换算保持不变：

| 阈值 | 作用点 | 换算（近似） |
| --- | --- | --- |
| `attackRatio` | 军团进攻所需的攻/守力量比 | 1.1 − 0.08×进攻性偏离 − 0.03×扩张欲偏离 + 0.02×防御性偏离 |
| `attackMinOrg` | 低于此组织度的军团改为休整 | 30 − 3×进攻性偏离 + 4×防御性偏离 |
| `warPowerRatio` | 对邻国宣战所需的力量优势 | 1.15 − 0.07×进攻性偏离 − 0.05×扩张欲偏离 + 0.04×结盟偏离 |
| `warMinDay` | 最早考虑开战的回合 | 5 − 进攻性偏离 − ⌊扩张欲偏离/2⌋ |
| `fatigueDays` | 战争持续多久后主动求和 | 10 + 2×容忍偏离 + 防御性偏离 |
| `peacePowerRatio` | 弱于对手多少时接受和平 | 0.85 − 0.05×容忍偏离 − 0.02×防御性偏离 |
| `offerMinDays` / `offerPowerRatio` | 向玩家求和的时机与力量比 | 5 + 容忍偏离 / 0.65 − 0.05×容忍偏离 − 0.02×防御性偏离 |
| `fortAppetite` | 边境要塞与工事偏好 | (防御性 − 1) / 4 |

v1 已落地行为仍有效：外交（宣战力量比、最早开战日、战争疲劳、和平接受/提出、目标国选择）、战斗（进攻力量比、休整组织度、受威胁城市回防）、建造（防御优先基础设施/要塞，贸易/和平优先农场，其余优先工厂）、征兵（进攻提高坦克/火炮比例，防御保留步兵）、随机性（`LCGRandom` + 倾向只移动掷点区间）。

v1“暂未实现”更新：

1. **阵营 / 联盟**：简化版已落地（单一领袖阵营、共同敌人、共享通行权、自动参战）；进攻/防御盟约区分、声望/信任仍待做。
2. **贸易 / 商路 / 港口 / 封锁**：仍未实现，“贸易立国”只表现为经济建筑偏好与较低战争意愿。
3. **附庸 / 傀儡 / 势力范围**：已落地三种契约 + 臣服度 + 契约改善 + 召唤参战 + 倒戈；属国独立宣战权、完整外交自主权仍待接入。
4. **意识形态**：没有意识形态标签、同阵营好感或政权更迭战争目标；“意识形态输出”暂按普通扩张型处理。
5. **结盟外交动作**：已落地创建/邀请/申请/退出与拒绝冷却；军援、保证独立等仍待接入。
