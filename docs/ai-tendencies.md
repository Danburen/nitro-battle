# AI 外交倾向（v2）——倾向驱动的附属国

本文档在 v1 基础上定义附属国规则。v1 的九种倾向、五维数值、阈值换算、观察入口全部保留不变；附属国不再有独立的“臣服度”维度，一切决策都读取该国自己的 `tendency` 五维。

## 1. 设计原则

- 附庸类型（合作 / 自治 / 压迫）是外交关系状态，可转换、可脱离；`tendency` 是国家固有性格，世界生成时固定。两者正交，不互相覆盖。
- **没有第 6 维**。`Nation` 上不存 `subservience`；“忠诚 / 桀骜”这类态度文案也已从逻辑和 UI 移除。玩家看到的是该国的 `tendency` 描述与唯一的状态值：**独立性**。
- 附庸 AI 仍只通过 `AIAction` / 领域函数的校验路径行动；倾向只移动决策阈值与掷点权重，不改变规则。`tendencyTuning()` 与 `vassalTuning()` 并列，后者从同一组五维派生。

代码结构：

```
src/game/ai/
  types.ts        AIController / AIAction / AITendencyId / AITendencyProfile / AITuning / VassalTuning
  tendencies.ts   9 种倾向、五维数值、阈值换算、vassalTuning()、种子洗牌、tooltip 文案
  standard.ts     StandardAI：攻击、推进、建造、征兵
  index.ts        统一出口
src/game/vassal.ts  契约、独立性、贡赋、召唤参战、求援、倒戈、契约改善
```

## 2. 独立性上限（按契约）

独立性是唯一的附庸状态值，不再统一为 0–100；它按契约有不同的上限，初值按上限的相同比例换算：

| 契约 | 独立性上限 | 初始独立性 | 高位判定（≥80%） | 达到上限 |
| --- | --- | --- | --- | --- |
| 自治型 | 100 | 55 | 80 | 和平脱离 |
| 合作型 | 300 | 90 | 240 | 和平脱离 |
| 压迫型 | 500 | 75 | 400 | 起兵反叛 |

`independenceOf()` 永远把数值钳制在所属契约的上限内；`independenceRatioOf()` 返回“当前值 / 上限”，所有高位判定都用它，避免不同量纲混用。

## 3. 独立性的变化来源

独立性**只能被动增长**，没有主动请愿、冷却或政治点花费（原 `petitionIndependence` / `petitionCost` / `VASSAL_PETITION_COOLDOWN` 已删除）。

- 每日被动漂移 `independenceDrift ≥ 0`，按上限缩放（上限越高漂移越快，三种契约的不稳定速度相近）；进攻/扩张倾向会略微加快漂移。
- 对宗主有利的贡献会**增加**独立性：上缴资源、人力、工业份额，以及每日上缴的政治点。
- 宗主国对附庸有利会**减少**独立性：合作型每天返还的 1 点保护政治点。
- 玩家附庸拒绝宗主的参战召唤，也会按上限的 5% 增加独立性。
- 宗主国陷入战争时，压迫型附庸额外加快漂移；达到 80% 后若宗主仍在战争，压迫型可能按 `flipWill` 提前起义。

## 4. 附庸专属阈值 `vassalTuning(profile, vassalType)`

全部由五维派生，无 per-nation 覆盖值：

| 阈值 | 含义 |
| --- | --- |
| `independenceDrift` | 非负的每日被动增长，按契约上限缩放 |
| `tributeCompliance` | 实际资源缴纳 = 名义比例 × 该系数（0.8–1.2），防御/结盟倾向高者更稳定 |
| `callToArmsAccept` | 参战基础意愿：进攻 + 扩张 + 战争容忍提高，防御倾向降低 |
| `flipWill` | 翻盘意愿：恃强凌弱 / 机会主义扩张 / 扩张欲提高，防御 / 结盟降低；压迫型 +0.25，自治型 -0.12 |
| `upgradeWill` | 契约改善意愿：结盟 / 和平倾向提高；压迫型 +0.15 |

## 5. 附庸决策（走与玩家相同的校验路径）

- **召唤参战**：宗主国对全部附庸拥有通行权（保持双向通行）。战争记录 `state.wars` 判定宗主是否为进攻方。
  - 压迫型：**无条件参加宗主的每一场战争**。
  - 进攻方是宗主：进攻/扩张倾向（高 `callToArmsAccept`）的附庸更愿参战；独立性达到 80% 时这类附庸更加积极。防御倾向强的不情愿。
  - 宗主是被侵略方：各附庸更愿意援助，防御倾向高的最积极。
  - 玩家作为附庸始终收到待处理召唤，由玩家自行决定。
- **请求外援**：所有附庸在独立性高位时都可能向第三方求援，强者与正在进攻宗主的国家优先；进攻/机会主义倾向的第三方更可能答应，并可能因此对宗主宣战。
- **契约改善**：压迫→合作→自治，需独立性达到上限的 60%、`upgradeWill ≥ 0.45`、政治点 ≥ 10、冷却结束；玩家作为宗主收到待处理请求，AI 宗主按其倾向立即决定。
- **倒戈（翻盘）**：独立性 ≥ 上限的 80% 且 `flipWill` 掷点通过时，若宗主较弱而进攻方明显更强（≥ 1.1 倍实力、接壤或正与宗主交战），附庸会倒向进攻方，若对方正与旧宗主交战则同时参战。`bully` / `opportunist` / `hegemon` 与压迫型最易发生；自治/合作型显著更少。玩家不会被静默设为新宗主。
- **独立 / 反叛**：自治与合作型达到上限时和平脱离（10 天停战）；压迫型达到上限时起兵反叛。

## 6. 观察入口与 tooltip

按 v1 第 5 节格式，附庸国国家卡片在“外交倾向”之后追加一段附庸状态，示例：

```
[[chip:#38d64b|格拉联邦]]
这个国家不结盟、不扩张、也不干涉他国，只在边境重兵设防，坚持武装中立。

+重视边防与工事，遭到入侵时坚决反击
~不愿主动开战，更倾向维持现状
~对扩张领土兴趣不大

附属于：[[chip:#c0392b|北方帝国]]（合作型）
独立性 120 / 300（40%） · 上缴资源 15%
```

不再显示“忠顺 / 桀骜 / 中立”等臣服态度染色；国家倾向本身已通过 `tendencyHelpBody()` 的签名特质呈现。五维数值、阈值权重等实现细节不在玩家文案中出现，只保留在本文档。

入口位置：

- 省份 / 州情报面板：外交倾向 `(i)` 追加附庸状态；
- 外交面板国家卡片：外交倾向 `(i)` + 独立的附庸状态行；
- 开局巡视的「国家详情」面板：同上；
- 玩家作为附庸时，外交面板顶部显示附属于哪国、独立性（当前值 / 上限 / 百分比）、贡赋与改善契约按钮。

## 7. 世界生成中的附庸

- 5 国以上开始生成附庸：5–7 国 1 个，8–9 国 2 个，10 国以上 3 个。
- **割地附庸**：从 AI 大国的边境州中切出一个新小国（不切断宗主首都连通性），作为该宗主的合作 / 自治 / 压迫型附庸。
- **独立附庸**：把已有的弱小国家附属于一个接壤且明显更强的邻国。
- 只生成一层关系：附庸不再拥有附庸，宗主国不会同时是别人的附庸。
- 每个国家只生成五维 `tendency`，不再生成或存储任何臣服度字段。

## 8. 与 v1 文档的衔接

- `tendencies.ts` 的 `AITendencyProfile` 只有五个轴；
- `vassalTuning(profile, vassalType)` 从这五个轴派生；`subservienceFor()` 已删除；
- `types.ts` 的 `AITuning` 通过 `VassalTuning` 暴露五个附庸阈值字段，非附庸国不读取；
- v1 第 4 节“暂未实现”第 3 条更新为：附庸层级已落地三种类型 + 独立性上限 + 契约改善 + 召唤参战 + 求援 / 倒戈；联盟已落地简化版，贸易仍待接入。

`tendencyTuning()` 的 v1 换算保持不变：

| 阈值 | 作用点 | 换算（近似） |
| --- | --- | --- |
| `attackRatio` | 军团进攻所需的攻/守力量比 | 1.1 − 0.08×进攻性偏离 − 0.03×扩张欲偏离 + 0.02×防御性偏离 |
| `attackMinOrg` | 低于此组织度的军团改为休整 | 30 − 3×进攻性偏离 + 4×防御性偏离 |
| `warPowerRatio` | 对邻国宣战所需的力量优势 | 1.15 − 0.07×进攻性偏离 − 0.05×扩张欲偏离 + 0.04×结盟偏离 |
| `warMinDay` | 最早考虑开战的回合 | 5 − 进攻性偏离 − ⌊扩张欲偏离/2⌋ |
| `fatigueDays` | 战争持续多久后主动求和 | 10 + 2×容忍偏离 + 防御性偏离 |
| `peacePowerRatio` | 弱于对手多少时接受和平 | 0.85 − 0.05×容忍偏离 − 0.02×防御性偏离 |
| `offerMinDays` / `offerPowerRatio` | 向玩家求和的时机与力量比 | 5 + 容忍偏离 / 0.65 − 0.05×容忍偏离 − 0.02×防御性偏离 |
| `fortAppetite` | 边境要塞与工事偏好 | (防御性 − 1) / 4 |

v1 已落地行为仍有效：外交（宣战力量比、最早开战日、战争疲劳、和平接受/提出、目标国选择）、战斗（进攻力量比、休整组织度、受威胁城市回防）、建造（防御优先基础设施/要塞，贸易/和平优先农场，其余优先工厂）、征兵（进攻提高坦克/火炮比例，防御保留步兵）、随机性（`LCGRandom` + 倾向只移动掷点区间）。

v1“暂未实现”更新：

1. **阵营 / 联盟**：简化版已落地（单一领袖阵营、共同敌人、共享通行权、自动参战）；进攻/防御盟约区分、声望/信任仍待做。
2. **贸易 / 商路 / 港口 / 封锁**：仍未实现，“贸易立国”只表现为经济建筑偏好与较低战争意愿。
3. **附庸 / 傀儡 / 势力范围**：已落地三种契约 + 独立性上限 + 契约改善 + 召唤参战 + 求援 / 倒戈；属国独立宣战权、完整外交自主权仍待接入。
4. **意识形态**：没有意识形态标签、同阵营好感或政权更迭战争目标；“意识形态输出”暂按普通扩张型处理。
5. **结盟外交动作**：已落地创建/邀请/申请/退出与拒绝冷却；军援、保证独立等仍待接入。
